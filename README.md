# Surf Lineup Code

An animated, top-down surf break that shows how to behave in a surf lineup. Pick a situation, set up the break, and watch how a considerate surfer handles it.

**Live site:** https://caidue.github.io/surf-lineup-code/

## Scenarios

- **Getting out:** reading the spot from the beach, paddling out, meeting a rider on the way out
- **In the lineup:** joining the queue (the textbook version, and a realistic one with an expert, regulars and a learner), priority, sharing an A-frame, drifting out of position, moving to another peak, outside and inside peaks
- **Breaking the rules:** dropping in, snaking, hogging waves
- **When it goes wrong:** missing a wave and getting caught inside, clean-up sets, sitting on the inside when a rider comes through
- **Getting in:** heading back to the beach, getting out of the channel current

## Conditions

Wave direction (right, left, A-frame), bottom (beach, reef, point), channel position, outside peak, inside section, crowd size and swell size. Every scenario adapts to the break you configure.

Each scenario has its own link, for example `#dropin`.

## Running it

It is a single self-contained `index.html` with inline CSS and JavaScript (fonts load from Google Fonts). Open it in a browser or serve the folder with any static host.
